# Известные ошибки и их решения — оглавление

Справочник багов разрезан по темам (28 октября 2026): по одному файлу на
подсистему, чтобы его можно было открыть, когда чинишь именно ее, а не
только искать. Записи перенесены дословно, ничего не выброшено.

**Как читать — поиском или по теме.** `python3 pipeline/docs_budget.py
--find "<слова симптома>"` ищет по всем файлам папки и по архиву и
возвращает запись с адресом «файл:строка». Чините подсистему — откройте ее
файл: у каждого документа в `docs/` в шапке назван его файл багов.

| файл | о чем | когда открывать |
|---|---|---|
| `known_issues/intake.md` | Приток: забор новостей, ворота, сырье, черновики, дубли | чините pipeline/ingest/ (sweep, promote, draft, triage, fetch, дубли), разбираете, почему сделка пришла поздно или дважды |
| `known_issues/publication.md` | Публикация и консоль: посты, канал, решения владельца, рутина публикации, отчеты | чините pipeline/publish/, send_drafts, approve, ship_decisions, ops_status, бота консоли |
| `known_issues/card.md` | Карточка сделки: поля, чтение источника, приемка, факты, оценка | собираете или чините карточку: стороны, сумма, статус, дата, отрасль, факты, review/accept/second_reading |
| `known_issues/text.md` | Разбор текста: регулярные выражения, дословность цитат, имена, числа, кавычки | пишете или чините правило разбора текста: регэксп, нормализация, проверка цитаты, границы имени |
| `known_issues/company.md` | Профили компаний: ФНС, ИНН, ЕГРЮЛ, банки, санкции, слияние профилей | создаете, переименовываете, сливаете профиль; чините ФНС, ИНН, банковскую отчетность |
| `known_issues/site.md` | Сайт: экраны, телефон, ассистент, API, доступ, подписки, выкладка интерфейса | правите static/index.html, main.py (экраны и API), проверяете экран в Playwright |
| `known_issues/ops.md` | Инженерное: git, тесты, CI, выкладка, контейнеры, документы, токены | падают тесты или сборка, конфликт в git, выкладка не доехала, правите документы |

**Когда сюда писать.** Сразу при первом обнаружении бага, не после повтора:
симптом, причина одной фразой, чем исправлено — в файл своей темы. Без
«кто нашел и когда», без отвергнутых гипотез. Потолка у файлов нет; потолок
у ОДНОЙ записи — 12 тыс. знаков (`test_docs.py`).
