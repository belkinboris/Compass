# Задание: крупные сделки из рейтингов AK&M, которых нет в базе (10 ноября 2026)

Сверка базы с рейтингами AK&M «M&A ТОП-30» 2022–2025 и месячными отчетами AK&M нашла сделки, которых в базе
нет (`verdict: missing`) или есть только соседний этап (`verdict: partial`, `our_related_id` — наша карточка
другого этапа, `note` — чем отличается). Твоя партия — `batch_akm_<N>.json` в этой папке (поле `items`).
AK&M (`akm_url`, `amount_akm`) — только подсказка, где искать: источник карточки — статьи изданий и сообщения
сторон. Сумма AK&M с пометкой «оценка AK&M» — это их собственная оценка, не цена сделки: в карточку не ставить.

## Что делаешь
Для каждого пункта — карточку сделки (`op: create`), если по чтению:
- сделка подтверждена двумя независимыми изданиями (или изданием плюс официальным сообщением стороны,
  раскрытием на e-disclosure, решением суда);
- ее нет в базе (ищи в `static/data/deals_promoted.json` по покупателю, продавцу, юрлицу, бренду, латиницей и
  кириллицей). Для `partial` — проверь, что это действительно другая сделка, а не тот же переход, описанный иначе.
Иначе — в `unresolved` с причиной (для «уже есть» — id карточки; для «не подтверждено» — не меньше 5 мест поиска).
Изъятие по суду (`seizure: true`) пиши по образцу изъятий (`gb98fcce5`): покупатель — государство, тема
«Национализация / иск Генпрокуратуры», суммы иска — не цена (в `eco.val` как «оценка ущерба/иска»).

## Правила полей (иначе приемка вернет)
- Дата: `ГГГГ-ММ-ДД` (день закрытия) или `ГГГГ`, не «ГГГГ-ММ»; не день статьи, если она позже события.
- Статус: «Закрыта» / «Подписана» / «Обсуждается» — по прочитанному.
- Сумма: названа сторонами или документом — как названа (`eco.sum` и `sum` одинаково); не названа — «Не раскрыта»;
  оценка аналитиков/СМИ — «N (по оценке)», кто оценил — в `eco.val`. Оценку AK&M в сумму НЕ ставить.
- `eco.share`: «N% акций АО «X»» / «N% доли в ООО «X»» / «—».
- `law.appr`: орган (ФАС, правительственная комиссия, суд, указ президента) — только если написан; иначе «—».
- Заголовок свой, глагол в прошедшем времени для закрытой сделки, кто купил что у кого (docs/card_title.md).
  Продавец в заголовке — только если узнаваемый. Без «ё», простым языком, тире « — », вложенные кавычки закрыты оба.
- Текст — пересказ своими словами (WRITING_BRIEF.md). Не «собеседник газеты» — «по данным РБК».
- Профиль предмета: найди в `companies`; нет — опиши в `profiles` черновика (`key, name как в ЕГРЮЛ, ind, desc
  одной фразой, inn, inn_reason`), в карточке `target_profile`. ИНН не нашел — `accepted_notes.no_profile.target`.

## Результат
`draft_akm_<N>.json`: `{"cards":[{"op":"create","key":..,"keep_id":null,"card":{...},"reading_note":".."}],
"profiles":[...],"legal_shorts":{},"unresolved":[{"key":..,"why":..}]}`. Базу не правь, git не трогай. Проверь:
`python3 pipeline/ingest/seizure_merge.py data/inbox/seizure_cards/draft_akm_<N>.json --defer-legal` — до нуля
находок. В ответ — коротко: сколько карточек, что в unresolved.
