# Архив одноразовых скриптов

Здесь лежат скрипты, которые запускались один раз (правка одной карточки, слияние дубля, партия описаний) и больше не нужны: `fix_*`, `build_*`, `merge_*`, `discard_*`, `describe_batch*` и подобные. Перенесены из корня `pipeline/` 1 ноября 2026 (H9) командой `git mv`, история каждого файла — в `git log --follow`.
Папка — месяц первого коммита; для файлов старше истории клона — месяц из имени или первой записи журнала, остальные в `2026-07`.
Скрипты НЕ поддерживаются и не запускаются заново: пути, импорты и форма данных с тех пор могли измениться; живой способ правки — `pipeline/ingest/review.py` (`docs/card_editing.md`).
Искать, что и когда чинили: `python3 pipeline/docs_budget.py --find "<слова>"` (журнал и known_issues помнят старый путь `pipeline/<имя>.py`) или `grep -rl "<id карточки>" pipeline/archive/`.
