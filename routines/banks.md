## Порядок работы

Ты — ежедневная рутина продукта «Компас» (репозиторий belkinboris/Compass, ветка main). Задача одного прогона: синхронизировать банковские финансы (активы, капитал, чистая прибыль) с Банком России.

ПРО ЭТУ СЕССИЮ. Она постоянная и привязана к репозиторию с момента создания (1 сентября 2026) — право на git push здесь есть всегда, инструмент add_repo не нужен и вызывать его не надо. Схема «новая сессия на каждый запуск» отброшена: у тех сессий не было ни прав на запись, ни инструмента add_repo вовсе. Рутина приходит сюда каждое утро, переписка накапливается — это нормально; каждый прогон самодостаточен и начинается с `git pull origin main`. Репозиторий уже склонирован; если контейнер пересоздали и папки нет — она появляется при старте контейнера автоматически.

ЛЮБОЙ СБОЙ — PushNotification одной строкой до 200 знаков, простым языком по правилу «Язык для людей» из CLAUDE.md (как сказали бы вслух, без внутренних терминов): git push не проходит после повтора (полный текст ошибки дословно); необработанное исключение вне сети до cbr.ru (сама сеть до cbr.ru бывает закрыта политикой прокси в отдельных сессиях — это не сбой, скрипт сам скажет об этом в выводе, пропусти прогон).

ПОРЯДОК:
1. `git pull origin main`.
2. `python3 pipeline/cbr_sync_bank_finance.py --write` — тянет форму 806 (активы/капитал, чистые, не путать со старым способом через форму 101) и форму 102 (чистая прибыль) для банковских профилей из pipeline/fns_registry.py (decision="bank", cbr_regnum задан), пишет static/data/bank_finance.json. Скрипт ИДЕМПОТЕНТЕН: если банки квартал/месяц не обновляли, он честно печатает «Без изменений» и не трогает файл — это НЕ ошибка, а обычный исход большинства прогонов (форма 806 квартальная, форма 102 помесячная). Сеть до cbr.ru недоступна — скрипт сам скажет об этом в выводе построчно по банкам, не считай это сбоем всего прогона.
3. Файл не изменился (`git status` чист) — коммитить нечего, это нормальный пустой прогон.
4. Файл изменился — `python3 -m pytest -q` (полный прогон, зелёным перед коммитом), затем `git pull --rebase origin main`, коммит по-русски (какие банки обновили данные и на какую дату — например «Сбербанк, ВТБ: обновлены активы на 1.07.2026»), `git push origin HEAD:main` (именно `HEAD:main`, не `git push origin main`: 31 августа поймали случай, когда под именем `main` в рабочей копии лежала отставшая локальная ветка, и обычная команда запушила бы её вместо реально сделанной работы). Отклонён — повторить `git pull --rebase` один раз.
