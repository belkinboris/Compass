# Рутина «тема Клод» — порядок работы

Ежечасно в :38. Заведена 17 октября 2026. Владелец и партнёр (Артём) пишут в тему «Клод»
группы-консоли задачи, правки и вопросы агенту; рутина их забирает,
выполняет как обычная рабочая сессия и отвечает в ту же тему.

Этот файл — единственный источник порядка работы. Если он расходится с тем,
что вы помните из прошлых прогонов этой сессии, прав файл.

## Что читать и когда

- **Всегда:** CLAUDE.md и этот файл. В пустом прогоне больше ничего.
- **Есть сообщения:** тот документ из карты в CLAUDE.md, которого касается
  просьба (правите экран — `docs/site_code.md`, карточку — `docs/card_editing.md`
  и т. д.). Как устроен приём сообщений — `docs/moderation_console_tech.md`.

## Порядок работы

ЕСЛИ РЕПОЗИТОРИЙ НЕ СКЛОНИРОВАН (папки `pipeline/ingest` нет) — сначала
`git clone https://github.com/belkinboris/Compass.git .`. ЕСЛИ `git push`
ОТКАЗЫВАЕТ АВТОРИЗАЦИЕЙ — `add_repo(owner="belkinboris", repo="Compass", access="push")`
и повторить.

1. `git pull --rebase origin main`.
2. `python3 pipeline/claude_topic.py` — печатает непрочитанные сообщения:
   `id` записи, `message_id` в Telegram, кто написал, на что ответил, текст;
   фото и файлы скачиваются в `data/inbox/claude/<id>.<расширение>` (путь
   напечатан — откройте его через Read).
3. **Пусто — стоп.** Без коммита, без сообщений в Telegram, без PushNotification.
4. **Есть сообщения.** По каждому (несколько подряд от одного человека —
   одна просьба, отвечать можно одним ответом на последнее):
   - Просьба большая (больше получаса работы) — сначала ответить
     «Взял, сделаю к …» (`--reply <message_id> --text "..."`), потом делать.
   - Делать как обычная рабочая сессия по CLAUDE.md: код → тесты → коммит в
     `main` → `git pull --rebase origin main` → push; тронули код —
     `python3 pipeline/release.py --write`. Данные базы — только скриптом:
     сухой прогон, потом `--write`, семантический diff к `origin/main`.
   - Ответить в тему простым языком (правило «Язык для людей» в CLAUDE.md):
     что сделано, что нет и почему, вопрос — если нужно решение человека.
     `python3 pipeline/claude_topic.py --reply <message_id> --text "..."`
     (длинный текст — `--text-file путь`; разметка — `--html`; картинка, например
     скриншот экрана, — `--photo путь [--caption "..."]`). Длинный ответ скрипт
     сам режет на части.
5. `python3 pipeline/claude_topic.py --consume <id1,id2,...>` — только те
   записи, на которые ответили. Не ответили (упало, не успели) — не помечать:
   следующий прогон подхватит.

## Чего не делать

- **Опасное — не делать, а спросить в теме:** массовое удаление данных или
  профилей, правка или удаление запусков рутин (расписаний), публикация в
  канал вне обычного порядка рутины публикации, смена ключей и переменных
  окружения, `push --force`, переписывание истории git. Вопрос — ответом на
  то же сообщение; запись не помечать прочитанной, пока нет решения, или
  пометить и держать вопрос в ответе — но не делать молча.
- Не создавать pull request без прямой просьбы; ветку не заводить.
- Не писать в другие темы консоли и в канал: ответ — только в «Клод».
- Не проверять отправку «на пробу» с выдуманным текстом: в контейнере
  рутины токен бота боевой, пробное сообщение увидят люди.

Контейнер поднимается пустым — зависимости ставит `.claude/hooks/session-start.sh`.
