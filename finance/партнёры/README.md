# Материалы для консультантов и компаний-партнёров

Папка собрана 12 октября 2026 после первой переписки о платном размещении
(Strategy Partners). Всё, что отправляется фирмам, — здесь, чтобы два
партнёра «Компаса» говорили одними словами и называли одни цены.

| файл | что это | кому |
|---|---|---|
| `01_описание_для_пересылки.md` | три варианта описания «Компаса»: три предложения, один экран, для Telegram | фирме, чтобы переслать коллегам |
| `02_условия_размещения.md` | что получает партнёр, что нужно от него, срок и цена; предложение прайса 2027 | фирме |
| `03_вопросы_и_ответы.md` | ответы на вопросы, которые задают, — готовые к отправке | нам, копировать в переписку |
| `04_соглашение_о_размещении.md` | проект соглашения на две страницы | фирме после согласования макета |
| `05_порядок_подключения.md` | шаги, шаблоны сообщений, что сработало и что исправить | нам |
| `Компас_для_консультантов.pdf` | условия размещения на двух страницах в стиле сайта | фирме |
| `pdf/` | исходник PDF (`build.py`, `index.html`) | — |

Цифры в текстах — на 12 октября 2026. Пересчитать:

```bash
python3 -c "import json;d=json.load(open('static/data/deals_promoted.json'));print(len(d['deals']),'сделок',len(d['companies']),'компаний')"
```

Пересобрать PDF после правки текста:

```bash
python3 finance/партнёры/pdf/build.py
```
