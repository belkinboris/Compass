# Материалы для партнёров — консультантов и компаний

| файл | кому |
|---|---|
| `Компас_для_консультантов.pdf` | фирме-консультанту, одна страница |
| `Компас_для_компаний.pdf` | компании, одна страница |
| `консультанты.md`, `компании.md` | те же тексты, чтобы править |
| `описание.md` | переслать коллегам внутри фирмы |
| `соглашение/Соглашение_о_размещении_модель.docx` | модельный текст, пропуски жёлтым |
| `соглашение/Соглашение_о_размещении_CarPrice.docx` | заполнено для ООО «СЕЛАНИКАР» |
| `соглашение/build.js` | собирает оба: `NODE_PATH=<путь к docx> node finance/партнёры/соглашение/build.js` |
| `порядок.md` | нам: шаги и шаблоны сообщений |
| `pdf/build.py` | собирает оба PDF: `python3 finance/партнёры/pdf/build.py` |
